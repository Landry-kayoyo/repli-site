📘 Où configurer SITE_URL sur PythonAnywhere ?
  1. Connectez-vous sur pythonanywhere.com
  2. Allez dans Files → naviguez vers votre dossier projet
  3. Ouvrez (ou créez) le fichier backend/.env
  4. Ajoutez la ligne : SITE_URL=https://landryit.pythonanywhere.com
  5. Sauvegardez, puis allez dans Web → cliquez Reload sur votre domaine
