📋 Comment obtenir un Page Access Token valide
  1. Va sur Meta for Developers → Graph API Explorer
  2. En haut à droite, sélectionne ton App Facebook (ou crée-en une gratuite)
  3. Clique "Generate Access Token" → choisis ta Page (pas ton profil personnel)
  4. Coche ces permissions : pages_manage_posts + pages_read_engagement
  5. Clique "Get Page Access Token" et copie le token généré
  6. Colle-le dans Paramètres du site → Token d'accès de la Page
⚠️ Important : Les tokens courts expirent en 1h. Pour un token permanent, utilise l'outil Access Token Debugger → "Extend Access Token" pour obtenir un token valable 60 jours (ou permanent pour les Pages).
